## Course Description
This course introduces the concepts and techniques for software verification and validation. Topics include software testing (unit, integration, system), static analysis, model checking, and formal methods.

## Prerequisites
- Introduction to Software Engineering
- Discrete Mathematics

## Textbooks
- *Introduction to Software Testing* by Ammann and Offutt
- *Software Testing and Analysis* by Pezzè and Young
